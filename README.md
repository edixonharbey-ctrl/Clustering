# 🍷 Clustering No Supervisado con K-Means y PCA (Wine Dataset)

Este repositorio contiene la implementación paso a paso, la evaluación y el informe técnico de un modelo de agrupamiento no supervisado mediante el algoritmo **K-Means** y reducción de dimensionalidad con **PCA** (Análisis de Componentes Principales) aplicado al conjunto de datos *Wine* de la UCI.

---

## 📌 1. Objetivo del Proyecto
Identificar la estructura de agrupamiento natural de 178 muestras de vino a partir de 13 características fisicoquímicas continuas, omitiendo la variable de etiqueta durante la fase de modelado para evaluar la capacidad del algoritmo en descubrir patrones implícitos.
